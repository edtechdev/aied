> **Synthesis:** Oktoma, Nugraha, and Hidayat (2026) introduce the Authentic AI-Assisted Writing Assessment (AAIWA) model, integrating authentic rubric-based assessment, condition-responsive AI feedback, and structured metacognitive reflection as a unified recursive architecture within Indonesian pre-service teacher education. The AAIWA prototype is a constrained hybrid system: a rule-based NLP layer governs all pedagogically consequential decisions while GPT-3.5-turbo serves exclusively as a language-articulation module. A mixed-methods R&D design engaged 75 pre-service teachers across three universities, demonstrating that embedding rubric criteria within the feedback engine and positioning reflection as dynamic input into subsequent feedback cycles supports authentic assessment and metacognitive development.

## Key Findings

**Integrated AAIWA model.** The AAIWA model unifies authentic rubric-based assessment, condition-responsive AI feedback, and structured metacognitive reflection into a single recursive architecture.

**Constrained hybrid system.** A rule-based NLP layer governs pedagogically consequential decisions while GPT-3.5-turbo acts only as a language-articulation module — "condition-responsive" feedback is rule-conditioned, not autonomous LLM reasoning.

**Recursive reflection.** Structured reflection functions as a dynamic input into subsequent feedback cycles rather than a post-hoc add-on, supporting [[metacognition]].

**Global South context.** The study addresses a design gap in Global South pre-service teacher education, engaging 75 pre-service teachers across three Indonesian universities.

**Implication.** The AAIWA model offers a design for [[authentic-assessment]] with AI in [[teacher-education]] that keeps pedagogically critical decisions in a rule-based, transparent layer while using LLMs for language articulation.
