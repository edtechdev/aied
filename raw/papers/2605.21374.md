# Combating Harms of Generative AI in CS1 with Code Review Interviews and a Flipped Classroom

**Authors:** Peter Fowles, Erik Falor, Sulove Bhattarai, John Edwards, Seth Poulsen
**Published:** 2026-05-20
**Venue:** arXiv:2605.21374 [cs.HC]

## Abstract
LLMs raise concerns for CS educators about students bypassing learning. This paper presents oral code review assessments combined with a flipped classroom to mitigate harms while allowing AI experimentation. Three semesters of data show insignificant exam score changes despite significantly increased AI usage (keystroke logs). Students responded positively to code reviews.
