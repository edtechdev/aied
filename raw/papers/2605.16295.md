# ANVIL: Analogies and Videos for Lecturers

**Authors:** Yuri Noviello, Anastasiia Birillo, Gosia Migut
**Published:** 2026-04-15
**Venue:** arXiv:2605.16295 [cs.CY; cs.AI; cs.CL; cs.GR; cs.HC; cs.MM]

## Abstract
ANVIL is a multimodal generative system that automates production of analogy-based instructional animations for CS topics. Pipeline: textual analogy generation → screenplay compilation → manim code generation with automated repair. Teacher evaluation found materials frequently rated adequate; educators responded positively to perceived value and usability.
