# Creating Learning Scaffolds for Engineering Design Using Concept Catalyst

**Authors:** Madhuri Singh, Gennie Mansi, Mark Owen Riedl
**Published:** 2026-05-19
**Venue:** arXiv:2605.20511 [cs.HC] — Accepted as Interactive Demo at ISLS 2026

## Abstract
Concept Catalyst uses LLMs to assist K-12 teachers with rapid creation of scaffold questions for engineering design challenges. The system decomposes challenges into concepts, allows visual manipulation, and proposes scaffolding questions for teacher modification. Differentiated from open-ended chat by structured, concept-driven interaction.
