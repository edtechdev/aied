# Concept Merge Workflow (absorbed → canonical)

Repeated editorial operation: fold one concept page into another (e.g. `engagement-metrics`
→ `student-engagement`, `over-reliance` → `cognitive-offloading`, `socratic-ai-dialogue` →
`socratic-method`). The absorbed slug keeps working via a 301 redirect; all inbound links
are rewritten to the canonical page. Validated end-to-end on 2026-08-18 (engagement-metrics
→ student-engagement).

## Merge map + redirects

- `src/data/conceptRedirects.ts` — add `'<absorbed>': '<canonical>'`. The `[slug].astro`
  page generates a meta-refresh stub for every redirect key. `curl -L` will NOT follow a
  meta-refresh; verify by grepping the stub for `url=/aied/concepts/<canonical>/`.
- `tooling/concept-index.md` — delete the absorbed entry from the canonical list, move it
  into the `## Merged / absorbed` section as `- <absorbed> → **<canonical>**`, decrement
  `**Total concepts:**`, and ABSORB the absorbed page's `phrases:` into the canonical entry
  (so future link-insertion resolves them to the canonical slug).

## Rewrite inbound links

- Rewrite every `[[<absorbed>]]` → `[[<canonical>]]` and `[[<absorbed>|display]]` →
  `[[<canonical>|display]]` (PRESERVE the pipe display) across ALL articles/ and concepts/
  markdown. Do this with a script; a simple `re.sub` on the wikilink pattern suffices.
- Plain-prose mentions of the absorbed concept (not wikilinks, e.g. "the engagement-metrics
  literature") should become `[[<canonical>|display]]` links per the inline-hyperlink rule.
- In a concept hub page (e.g. `concepts/ai-education.md`) that lists BOTH the canonical
  name and the absorbed name as separate items, COLLAPSE the duplicate — keep only the
  canonical item, since both now resolve to the same page.

## Tags: KEEP them, do not rewrite

The established convention is to PRESERVE the absorbed concept's `tags:` entries across all
pages (the canonical page carries the absorbed tag as an alias: `cognitive-offloading` keeps
`over-reliance`, `game-based-learning` keeps `gamification`). Do NOT mass-rewrite tags.

## Sidebar + index + count

- `src/data/conceptIndex.ts` — remove the absorbed slug from its group.
- `index.md` — remove the `- [[<absorbed>]] — Title` line; decrement `**Total pages:**`
  (= real article+concept file count, recount with `ls | wc -l`).
- `journal.md` — remove the same line; decrement `**Total entries:**`. Bump the
  `**Last updated:**` date on both to today.
- `tooling/SCHEMA.md` — tag example lists may still mention the absorbed tag;
  that is fine (the tag is preserved), leave them.

## Agent-ready artifacts (MUST regenerate)

- `public/llms.txt`, `public/llms-full.txt` — `python3 tooling/scripts/generate-llms-files.py`.
- `public/schema/concepts.json` AND `public/schema/corpus.json` — each contains a
  `DefinedTerm` node per concept. On merge, remove the absorbed node (match on
  `termCode == '<absorbed>'`) and re-dump with `ensure_ascii=False, indent=1`. These files
  are committed source copied verbatim into `dist/`; they are NOT regenerated by `npm run
  build`, so a merge must update them manually. (The 2026-08-17 merge SKIPPED this and left
  stale `over-reliance`/`gamification` nodes — the 2026-08-18 session fixed engagement-metrics
  but the older stale nodes remain. `articles.json` is all `ScholarlyArticle` nodes, no
  concept DefinedTerm, so it needs no change.) Article `keywords` fields referencing the
  absorbed tag are preserved (tags kept), so don't strip those.

## Verify + deploy

1. `npm run build` (astro check + build + pagefind + sitemap) — must be green, ~0 broken links.
2. Confirm no `[[<absorbed>]]` wikilinks remain: `grep -rn "\[\[<absorbed>" articles concepts | wc -l` → 0.
3. Confirm the redirect stub: `dist/concepts/<absorbed>/index.html` contains
   `url=/aied/concepts/<canonical>/`.
4. `git add -A && commit && push`. A green push ≠ green deploy: `gh run list --repo edtechdev/aied`
   and confirm BOTH `Build & Verify` and `Deploy Astro to Pages` finish `success`.
5. Live check: `curl -s https://edtechdev.github.io/aied/concepts/<canonical>/` should show the
   merged sections; `curl -s https://edtechdev.github.io/aied/concepts/<absorbed>/` returns the
   redirect stub. Note CDN cache delay (~4–5 min) before new content appears live.
