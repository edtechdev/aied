*انگریزی صفحے کا خودکار ترجمہ، جو ابھی تک کسی مقامی بولنے والے کے ذریعے جانچا نہیں گیا۔*

Code Viva پروگرامنگ کورس کے ہر طالب علم کے لیے [[oral-assessment|وائیوا]] کا تحریری اور وقت بند نسخہ چلاتا ہے، ہر ایک کے لیے تقریباً پندرہ سے بیس منٹ، بغیر کسی استاد کے کمرے میں موجود ہونے کے۔ یہ طالب علم کے جمع کردہ کوڈ اور commit تاریخ پڑھتا ہے، اس طالب علم کے اپنے فنکشنز، ناموں اور commits پر چار سے چھ سوال لکھتا ہے، اور ہر طالب علم کو جواب دینے کے لیے ایک ذاتی لنک دیتا ہے۔

## اس سے آپ کیا کر سکتے ہیں

جمع شدہ کام Gradescope ایکسپورٹ، Canvas ڈاؤن لوڈ زپ، فی طالب علم فولڈر والی زپ، یا read token کے ساتھ GitHub Classroom سے آتا ہے۔ استاد سیشن کی لمبائی، سوالوں کی تعداد اور آخری تاریخ مقرر کرتا ہے، اضافی وقت 1.25x سے 3x پر نشان زد کرتا ہے، اور لنک بھیجنے سے پہلے بنے ہوئے سوالات پڑھتا، بدلتا یا بدل دیتا ہے۔ سوالات recursion کے base cases، edge guards، ڈیٹا اسٹرکچر کے انتخاب، مبہم ویری ایبل ناموں، پیمانے اور ٹریسنگ، اسائنمنٹ کی تفصیل کے جملوں، اور commit کے نمونوں جیسے ایک ہی بار میں بڑا commit یا رات گئے commit کو ڈھکتے ہیں۔ جوابات response code کے طور پر واپس آتے ہیں، اور جائزے کی اسکرین ہر ٹرانسکرپٹ کو تجویز کردہ 0 سے 3 اسکور کے ساتھ دکھاتی ہے، ساتھ ان جملوں کے جن پر وہ ٹکا ہے، اور ایک فلیگ قطار جو ترتیب دی جاتی ہے کہ بات چیت کتنی ضروری ہے۔ نتائج CSV میں برآمد ہوتے ہیں، اور گیارہ ڈیمو کورسز قاری کو فرضی ڈیٹا پر پورا چکر آزمانے دیتے ہیں۔

## یہ کس کے لیے ہے

پروگرامنگ کورسز کے اساتذہ جو ایسی شہادت چاہتے ہیں کہ طالب علم اپنا کوڈ سمجھا سکتا ہے، اور جو سب سے بات کرنے کے بجائے چند طلبہ کی مختصر فہرست سے بات کرنا پسند کریں گے؛ commit والے سوالات اسے [[process-oriented-assessment]] کی ایک شکل بناتے ہیں۔

## نوٹس اور احتیاطیں

سب کچھ براؤزر میں چلتا ہے: کورس مقامی اسٹوریج میں JSON ایکسپورٹ کے ساتھ رہتا ہے، سوالات لنک کے اس حصے میں سفر کرتے ہیں جو براؤزر سرور کو نہیں بھیجتے، اور جوابات صرف کوڈز کی صورت میں واپس آتے ہیں جو طلبہ خود بھیجنا چنیں، اس لیے کوئی طالب علم ڈیٹا کسی فریقِ ثالث تک نہیں پہنچتا۔ سوال بنانے والا rule-based ہے، ماڈل سے چلنے والا نہیں۔ خود اوزار کے بیان کے مطابق اس کا کوڈ ریڈر heuristic ہے، اس لیے غیر معمولی فارمیٹنگ یا macros کوئی فنکشن چھپا سکتے ہیں، اور اسکور الفاظ جاننے کو کوڈ سمجھنے سے زیادہ انعام دے سکتا ہے، اسی لیے اسکور ایسی تجاویز ہیں جنہیں استاد منظور کرتا ہے اور اسی لیے یہ نصیحت کرتا ہے کہ داؤ کم رکھا جائے۔ کوئی لائسنس اور کوئی سورس ریپوزٹری شائع نہیں ہوئی، اور چونکہ لنک سوالات ساتھ لے کر چلتے ہیں وہ چند کلوبائٹ تک پہنچتے ہیں، یعنی اتنے لمبے کہ سیکھنے کے نظام کے پیغام کے خانے میں لپٹ جائیں۔
