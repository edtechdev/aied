*Terjemahan mesin otomatis halaman berbahasa Inggris ini, yang belum ditinjau oleh penutur asli.*

**Pustaka Prompt eLearning** adalah repositori GitHub oleh Sunil Iyer yang mengumpulkan [[prompt-engineering|prompt AI]] yang ditulis untuk perancang instruksional, pengembang eLearning, dan manajer proyek L&D. Dua puluh dua file prompt berada di tujuh folder kategori — desain instruksional, pengembangan konten, Articulate Storyline dan Rise, penilaian, manajemen proyek, jaminan mutu dan tinjauan, serta media AI. Setiap file adalah blok salin-tempel dengan placeholder dalam kurung, dan masing-masing menyebut teori belajar yang diterapkannya; dokumen referensi pendamping mendaftarkan enam puluh teori dalam enam keluarga. Kerangka penulis adalah bahwa prompt generik menghasilkan konten yang tampak instruksional tanpa berpijak pada cara orang belajar, dan bahwa menandai setiap prompt dengan teori yang dinamai itulah yang membuat koleksi ini dapat dipakai.

## Apa yang dapat Anda lakukan dengannya

Pustaka ini disusun menurut tugas produksi, bukan menurut alat. Prompt desain instruksionalnya mencakup analisis kesenjangan terhadap [[bloom-taxonomy|taksonomi Bloom]], audit beban kognitif, mengubah catatan SME menjadi rencana pelajaran, memilih teori, merencanakan modul sembilan peristiwa Gagné, pemetaan tindakan, dan audit aksesibilitas UDL. Prompt konten membangun kerangka storyboard, naskah narasi, dan tinjauan motivasi ARCS. Prompt Storyline dan Rise menangani logika pemicu, urutan blok Rise, dan spesifikasi interaksi HTML5; prompt penilaian mencakup skenario bercabang, bank soal, dan perencanaan evaluasi Kirkpatrick; dan dua prompt manajemen proyek serta dua prompt jaminan mutu melengkapi koleksi.

Prompt-prompt ini tidak bergantung pada alat — README menyebutkan bahwa prompt itu berjalan di Claude, ChatGPT, atau Gemini — dan panduan kontribusi meminta setiap penulis memberikan tiga sampai lima "Catatan" singkat yang memuat tips iterasi.

## Untuk siapa

Untuk perancang instruksional dan pengembang teknologi pendidikan yang menginginkan titik awal berlabel teori, bukan kotak prompt kosong, serta tim L&D yang membangun kursus Articulate Rise atau Storyline. Ia cocok untuk seseorang yang sudah tahu teori mana yang cocok untuk sebuah proyek dan menginginkan kerangka prompt. Ini pustaka produksi profesional yang ditujukan pada pembelajaran orang dewasa dan di tempat kerja, bukan alat kelas untuk siswa.

## Catatan dan peringatan

- **Jumlahnya tidak sama.** Lencana README dan tabel kategorinya sama-sama menyebut 23 prompt; repositori berisi 22 file prompt Markdown, dan tabel indeksnya berhenti di 22.
- **Penandaan teori adalah pemetaan milik penulis.** Tidak ada yang memvalidasi bahwa sebuah prompt menerapkan teori yang disebutkannya. "Berbasis bukti" dan "siap produksi" adalah klaim penulis, dan setiap keluaran masih perlu diperiksa substansinya sebelum masuk ke dalam kursus.
