# 教員にはAIに関してどのような能力が必要ですか?

**教員の能力は、プロンプトの作成をはるかに超えたものであるべきです。** この知識ベースの[[ai-literacy|AIリテラシー]]の統合は、4つの広い次元を特定しています。

- AIの能力と限界に関する**基礎的な理解**。
- AIツールを使う**実践的な能力**。
- 正確さ、偏り、適切さ、不確実性の**[[critical-thinking|批判的評価]]**。
- 誠実さ、プライバシー、[[equity-in-ai-education|公平性]]、[[governance]]といった問題を含む**[[ethics|倫理的]]かつ制度的な自覚**。

## 教授法の層

教員にとって、それらの次元にはさらに教授法上の層が必要です。教員は以下ができるべきです。

- 学生が保持すべき認知的作業が何であるかを判断する。
- 学習目標と整合するAIの活用を選ぶ。
- AI時代において妥当な評価を設計する。
- 学生にAIの利用を検証し、管理することを教える。
- [[hallucination-risk|ハルシネーション]]、過度の依存、[[ai-sycophancy|お世辞的同調]]を認識する。
- 自動化よりも[[human-in-the-loop-ai|人間の判断]]が優先されるべき場がいつであるかを知る。

教員はまた、AIを孤立した道具として見るのではなく、[[generative-ai|生成AI]]を支えるワークフローがどう組み合わさっているかを評価できるだけのシステム理解も必要としています。[[teacher-ai-competency|教員のAI能力]]と[[educational-development|教員開発]]を参照してください。

## 自信は能力ではない

知識ベースに要約されている研究はまた、自信と能力を同一視することに警鐘を鳴らしています。[[self-report-measures|自己申告]]されたAIリテラシーは実証された能力と大きくかけ離れることがあり、自信に関する調査だけよりも**実績に基づく専門能力開発と本物の実践**が望ましいとされています。教員の[[agentic-ai|マルチエージェント]]ワークフローに関する研究はさらに、AIの統合においてシステム思考、教授法上の信念、[[self-efficacy]]が相互作用することを示唆しており、専門能力開発は画一的なツール講習ではなく、差別化されたものであるべきだということです。

## 専門能力開発が実際に動かすもの — そして動かさないもの

最近の高等教育研究は、教員の能力がどこで強く、どこで崩れるかに具体的な数字を当てはめています。[[tpack]]-21尺度を用いた[[sutedjo-faculty-genai-tpack-21-2026|米国の大規模研究大学における教員127人を対象とした調査]]は、自己認知された[[pedagogy|教授法的]]内容知識が高いこと(M = 4.70)と、[[tpack|内容知識]]が天井近いこと(M = 5.15)を見出しましたが、技術統合領域は著しく低く — 技術的教授法的知識(M = 2.62)、技術的内容知識(M = 2.75)、そして包括的TPACK(M = 2.55、7つのうち最低)でした。内容の専門知識はGenAI統合知識を予測しませんでした(CKの相関は r = .11–.15、いずれも非有意)ので、教員開発は**科目の習熟がそのまま移ることを前提にできず**、意図的で[[discipline-specific-aied|分野固有]]のプログラムを通じて[[generative-ai|生成AI]]の能力を築くべきです。3つの技術統合領域が r = .81–.91 で相関していたことから、それらは個別の技能としてではなく、共通の基盤として教える価値のある単一のGenAI統合能力として機能する可能性があります。

研修にできることとできないことは同じく示唆に富みます。[[pishtari-teacher-ai-training-learning-design-2026|高等教育の教員13人を対象とした被験者内計画の研究]]では、教員に[[conversational-ai|チャットボット]]を与えたところ、彼らの[[learning-design|学習設計]]の質が有意に向上しました — ブルームの高次タスクを2つ以上達成した割合は**41.7%から91.7%**に上昇し(p = .01) — 知覚された認知的負荷も大きく低下しました(中央値 6.33 から 3.33、p = .004)。その上に重ねられた教授法上の[[prompt-engineering|プロンプト技法]]研修は**質をさらに向上させることはなく**、負荷をわずかに増やしました。言い換えれば、AIへのアクセスは[[teacher-role|教授行動]]を容易に変えますが、より深い能力は一度の講習以上のものを必要とし、質の向上だけでは教員がその実践を内面化したことを証明しません。

## 基準、主体性、アイデンティティ

能力は制度的な問題でもあります。[[crompton-faculty-technology-integration-standards-2026|米国の28機関、11か国にわたる114名を対象としたデザインに基づく研究]]は、既存の枠組み([[tpack]]、[[samr-model|SAMR]])や教育者の基準(ISTE、UNESCO、DigCompEdu)が[[k-12]]の教員か、教授の次元のみを対象としているため、教員の役割全体にわたる6つの教員技術基準 — Instructor、Coordinator、Leader、Researcher、Learner、Contributor — を作成しました。

[[dai-genai-frenemy-teaching-autonomy-2026|27か国の教員287人を対象とした調査]]は、導入が純粋に技術的な枠組みに収まらない理由を示しています。精緻化されたモデルは行動意図の分散の**79.8%**を説明したものの、知覚された人為的な[[agency|主体性]]は有用性を通じてのみ間接的に意図に影響し、**リスク回避は有意な負の予測因子**でした(−.163)。教員は自分自身の利用よりも、学生の[[cognitive-offloading|過度の依存]]と[[academic-integrity|誠実性]]のリスクをはるかに心配していました。導入は自動化の魅力ではなく、文脈に敏感な判断にかかっていました。最後に、[[ai-integrated-teaching-identity-tensions|経験豊富な大学人2人へのインタビュー]]は、AIの統合が再発する**アイデンティティの緊張** — 教授法対プラットフォーム、教育者対支援役、配慮対遵守 — を生じさせ、それが[[pedagogy|教授法]]的価値に根ざした*原則ある選択性*を通じて乗り越えられることを示唆しています。したがって能力には、AIを使う技能だけでなく、*AIを使わない*という専門職としての判断も含まれます。
