AI を組み込んだ課題のためのビルダーで、AI Education Labs, Inc. が運営している。前提は、無制限のチャットボットへの対抗策は禁止ではなく構造だというものである。教員が学生の通る段階を定め、各段階でモデルが果たす役割を決め、どこまでモデルに頼ってよいかを設定する。課題はプロンプト文書として配布されるのではなく、参加リンクとして公開される。

## これでできること

- **課題ごとにモデルの役割を設定する。** ビルダーはチューター、ソクラテス式の質問者、フィードバック提供者、リサーチアシスタントのプリセットとカスタムプロンプトを用意しており、課題が求める振る舞いをアシスタントにさせられる。
- **段階の間にゲートを置く。** 進む前に自分の推論を説明することを求める設定ができ、AI の支援は段階ごとに上限を設けられる。画面には開かれたアクセスではなく残り回数が表示される。
- **作業面を選ぶ。** 学生は余白コメント付きの文書ページに書き、課題に合う場合はチャットやノートブックのレイアウトも使える。
- **公開して、成果だけでなく思考の過程を見る。** 参加リンクで学生が登録し、進捗は随時保存され、教員は各学生の対話記録を読み、CSV または Markdown で書き出せる。
- **AI で下書きし、その後で整える。** セットアップはいくつかの質問、アップロードした既存の課題、以前の課題から始められ、教員側のアシスタントが最初の下書きを埋める。

公開されている例は想定される範囲を示している。証拠と証言を扱う物理の課題、AI インターンの説明にある推論の誤りを診断する生物の演習、ニュース記事が研究デザインを正しく記述しているかを確かめる心理の課題である。

## 誰に向いているか

AI のポリシーを [[learning-design|学習デザイン]] に担わせたい高等教育の教員に向いている。つまり、モデルが使われたかどうかを取り締まるのではなく、課題の中でどう使えるかを制約したい場合である。ゲートと役割設定は [[guardrails|ガードレール]] を設計時に表現したものであり、このアプリケーションは機関全体のチャット運用ではなく授業課題を対象にしている。

## 注意点と限界

- **パイロット段階。** 利用規約は、サービスが現在パイロットとして無償で提供されており、有償プランが告知のうえ導入される可能性があり、機能が変更または廃止されることがあると述べている。公開の料金ページはなく、料金はサインイン後にしか確認できない。
- **プライバシーの主張は設計に基づくもので、注意して読む価値がある。** 学生は課題ごとにランダムなセッション識別子を受け取り、アカウントとセッションの対応は Repertoire のサーバーに留まり、モデルは匿名のセッション、課題の文脈、学生の文章を受け取る。ただしポリシー自身が限界を記している。学生が自分の身元を明かす文章を入力すれば、それは他の文章と同じように送信され、担当教員はその対話記録を読むことができる。
- **第三者による推論。** 応答は Anthropic の Claude API で生成され、利用不可やレート制限時には OpenAI の API が予備として使われる。ポリシーによれば、2026 年 9 月時点の商用条件は API の入力と出力を学習に使わないものとされている。機関はウェブページではなく自らの契約でこれを確認すべきである。
- **採点システムではない。** ポリシーと規約はいずれも「目的達成」のようなアシスタントの判断を教員のための補助と位置づけている。成績や学務上の決定は教員と機関に残り、学生への [[ai-use-disclosure|AI 利用の開示]] をどうするかは教員が決める。
- **米国でホストされている。** データは Vercel のホスティング下の Google Cloud Firestore に置かれ、ポリシーは教育記録を扱う場合の FERPA 上の義務に言及している。米国外の利用者には、データが米国で処理されることが伝えられている。
