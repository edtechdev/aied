**Master Instructional Design** is a Claude skill that packages a working practitioner's method as an on-demand advisor: fifteen engagement modes, thirty-one reference files loaded only when relevant, and a nine-dimension audit framework spanning alignment, learner-centeredness, cognitive load, practice and transfer, feedback quality, engagement, visual design, inclusion, and consulting posture. It covers the full learning-and-development spectrum rather than course design alone, from needs and task analysis through eLearning authoring in Storyline, Rise and Captivate, facilitation and virtual workshop design, learner experience design, agile practice for L&D teams, [[assessment|evaluation planning]] with Kirkpatrick's levels and Phillips ROI, and organizational learning strategy for chief learning officers. Its reference files also carry the academic canon of the field, and it generates populated artifacts such as facilitator guides, alignment matrices and content audits, diagnosing a project before drafting anything.

The skill ships with a supporting harness: two subagents, one for intake interviews and one for [[assessment|evaluation]] architecture, hooks that route each prompt to the relevant reference file and guard its own files against accidental edits, cross-session project memory, and optional connectors for Perplexity, Google Drive and Notion that use each reader's own credentials. It installs into Claude Projects as an uploaded skill, or into Claude Code by copying the skill, hooks and agents into a project's configuration.
