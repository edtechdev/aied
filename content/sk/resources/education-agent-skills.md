*Automatický strojový preklad tejto anglickej stránky, ktorý ešte nebol skontrolovaný rodeným hovorcom.*

**Education Agent Skills** je knižnica 165 agentných zručností pre učiteľov, vedúcich škôl a ľudí, ktorí stavajú vzdelávacie nástroje. Zručnosti sú zoskupené do dvadsiatich domén pokrývajúcich pedagogiku, vedu o učení, [[curriculum-design|kurikulum]], hodnotenie a regeneráciu a každá je napísaná tak, aby ju načítal [[agentic-ai|agent]], nie aby sa čítala ako dokument.

## Čo s tým môžete robiť

Zručnosti sa inštalujú do Claude Code, Codex a Hermes, buď ako plugin, alebo skopírovaním priečinkov, takže tá istá knižnica funguje na viacerých agentných povrchoch. Hostovaný MCP server sprístupňuje zbierku ako nástroje pre agentov, ktorí si zručnosti nevedia nainštalovať lokálne, a repozitár dodáva register aj vopred zostavený balík, aby server mohol zbierku obsluhovať bez čítania jednotlivých súborov pri nasadení.

Odlišujúcim tvrdením projektu je jeho ukotvenie: zručnosti citujú dôkazy, o ktoré sa opierajú, a vlastná história repozitára ukazuje, že disciplína sa vynucuje, nie len tvrdí, vrátane zlúčenej opravy, ktorá odstránila nepodložené priradenie a opravila opis testovaného zabezpečenia v citovanej štúdii.
