**Education Agent Skills** ist eine Bibliothek von 165 Agent Skills für Lehrkräfte, Schulleitungen und Menschen, die Bildungswerkzeuge bauen. Die Skills sind in zwanzig Bereiche gruppiert, die Pädagogik, Lernwissenschaft, [[curriculum-design|Curriculum]], Assessment und Weiterentwicklung umfassen, und jeder ist so geschrieben, dass er von einem [[agentic-ai|Agenten]] geladen wird statt als Dokument gelesen zu werden.

## Was man damit tun kann

Skills installieren sich in Claude Code, Codex und Hermes, entweder als Plugin oder durch Kopieren der Ordner, sodass dieselbe Bibliothek über mehrere Agenten-Oberflächen hinweg funktioniert. Ein gehosteter MCP-Server stellt die Sammlung als Werkzeuge für Agenten bereit, die Skills nicht lokal installieren können, und das Repository liefert sowohl eine Registry als auch ein vorgebautes Bündel, damit der Server die Sammlung ausliefern kann, ohne beim Deployment die einzelnen Dateien zu lesen.

Das herausstechende Merkmal des Projekts ist seine Fundierung: Skills belegen die Evidenz, auf der sie ruhen, und die Geschichte des Repositorys zeigt, dass diese Disziplin eingefordert und nicht nur behauptet wird – einschließlich einer eingefügten Korrektur, die eine ungestützte Zuschreibung entfernte und die Beschreibung einer getesteten Schutzmaßnahme in einer zitierten Studie richtigstellte.

## Anmerkungen und Vorbehalte

Die Bildungs-Skills, die Dokumentation und die Curriculum-Materialien stehen unter CC BY-SA 4.0, sodass Weiterverwendung und Bearbeitung offen sind, während abgeleitete Werke dieselbe Lizenz tragen müssen. Zwei betriebliche Details sind wichtig, wenn Sie es einsetzen. Der gehostete MCP-Endpunkt erfordert Tokens und ist nicht für alle offen, und weil der Server eine festgeschriebene Momentaufnahme statt der SKILL.md-Dateien ausliefert, erscheint ein Skill, den Sie hinzufügen, ohne das Bündel neu zu bauen und festzuschreiben, selbst nach einem Redeployment nicht auf dem Live-Server. Die Bibliothek wird von Gareth Manning gebaut, einem Pädagogen und Curriculum-Designer, und die Lizenzbedingungen gelten speziell für die Bildungsinhalte.
