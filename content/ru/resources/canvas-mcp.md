**Canvas MCP** — открытый сервер Model Context Protocol от Вишала Сачдева, который подключает ИИ-клиент к экземпляру Canvas LMS: агент может перечислить предстоящую работу студента, прочитать задания и сдачи курса, отправить сообщение классу или провести аудит курса на доступность — всё через инструменты, которые предоставляет сервер, а не через сбор данных с экрана на лету.

## Что с этим можно делать

Сервер поставляет три семейства инструментов. Студенческие инструменты отвечают на вопросы «что сдавать на этой неделе», «всё ли я сдал», «сколько попыток теста у меня осталось» через собственные конечные точки `self` Canvas. Инструменты преподавателя перечисляют и создают задания, читают сдачи, выставляют оценки массово, отправляют сообщения и выгружают аналитику по заданиям. Инструменты проектировщика обучения охватывают проверки качества курса и сканирование доступности по WCAG. Всего доступно до 128 инструментов, хотя профиль по умолчанию регистрирует меньше, а инструменты за функциональными флагами увеличивают это число. Поверх инструментов восемь навыков агента упаковывают многошаговые рецепты — недельный план, утренняя проверка здоровья курса, дерево решений для массового оценивания, конвейер взаимного рецензирования, аудит курса перед семестром — и устанавливаются в более чем 40 агентов через `skills.sh`.

## Для кого это

Преподаватели, которые хотят, чтобы агент выполнял рутинное чтение и переписку вокруг курса, и [[institutional-ai-infrastructure|институциональные команды]], оценивающие, до чего агент, подключённый к LMS, действительно может дотянуться. Проектировщики обучения получают здесь ближайшее к автоматической рецензии курса. Проект — разобранный пример [[agentic-ai|агентных инструментов]] на уровне LMS одного учреждения, а не универсального чат-бота.

## Примечания и оговорки

Настройка локальная: Python 3.11 или новее, токен и URL API Canvas и MCP-клиент, плюс расширение для Claude Desktop с запуском двойным щелчком. Публичный размещённый сервер выведен из эксплуатации, поэтому общее развёртывание означает самостоятельный хостинг за собственной аутентификацией учреждения. Инструменты записи закрыты шлюзом: HTTP-серверы доступны только для чтения, если инструменты записи явно не разрешены, удаления требуют токенов подтверждения, а выполнение кода идёт в песочнице, которая при сбое закрывается. Средства приватности включаются по выбору: анонимизация ответов, маскирование электронной почты и фильтрация персональных данных должны быть включены, и README аккуратно оговаривает, что они могут поддерживать обязательства по FERPA, но не устанавливают соответствие, которое зависит от развёртывания и поставщика ИИ. Телеметрии в сервере нет, но Canvas и выбранный клиент ведут собственные журналы. Проект под лицензией MIT, активно развивается, и его собственные руководства — источник истины о текущих именах инструментов и конфигурации.
