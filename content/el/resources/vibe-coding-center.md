*Αυτόματη μηχανική μετάφραση αυτής της αγγλικής σελίδας, που δεν έχει ακόμη ελεγχθεί από φυσικό ομιλητή.*

Το **Vibe-Coding Center** είναι ο δωρεάν οδηγός πεδίου του Miguel Guhlin για έναν εκπαιδευτικό που θέλει να [[vibe-coding|φτιάξει με vibe coding]] ένα μικρό στατικό εκπαιδευτικό site με έναν βοηθό κώδικα ΤΝ — ένα exit ticket, ένα κουίζ, ένα χαρτοφυλάκιο τάξης — χωρίς να παραδώσει μαζί του ένα εκτεθειμένο κλειδί API ή δεδομένα μαθητών.

## Τι μπορείτε να κάνετε με αυτό

Τρία αρχεία οδηγιών φέρουν την καθοδήγηση: `WEB_DESIGN.md`, `EDU_COMPLIANCE.md` και `securevcc.md`. Κατέβασέ τα στη ρίζα ενός έργου, συμπλήρωσε το πρότυπο σύντομης περιγραφής του έργου και μετά ζήτα από τον βοηθό να διαβάσει και να εφαρμόσει και τα τρία· ο οδηγός είναι ρητός ότι η παρουσία δεν είναι ενεργοποίηση, οπότε τα αρχεία πρέπει να ονομάζονται στο αίτημα. Αναγνώσιμοι οδηγοί εξηγούν το καθένα, μαζί με μια περιήγηση «Τρεις ουσιώδεις έλεγχοι πριν το μοιραστείς»: συλλογή λιγότερων δεδομένων μαθητών, επιθεώρηση ενός εκτεθειμένου κλειδιού API και προσαρμογή του σχεδιασμού ενός εργαλείου στη μαθησιακή του εργασία. Η πλήρης δέσμη προσθέτει το ίδιο το site, πακέτο προτροπών, έλεγχο κυκλοφορίας και σενάρια επανακατασκευής, με ένα μανιφέστο SHA-256 για το κατέβασμα.

Η συνοδευτική σελίδα [παραδειγμάτων του EduSynth Hub](https://mguhlin.github.io/funquiz/examples.html) δείχνει τα αποτελέσματα ως λειτουργικά στατικά εργαλεία και όχι ως στιγμιότυπα οθόνης: μια γεννήτρια exit ticket που γράφει μια ερώτηση σε επιλεγμένο επίπεδο SOLO Taxonomy, ένα χαρτοφυλάκιο φοιτητή που είναι ένα μόνο αρχείο HTML στο GitHub Pages, και μια αναζητήσιμη βιβλιοθήκη πόρων επαγγελματικής ανάπτυξης, όλα να τρέχουν στην πλευρά του πελάτη χωρίς σύνδεση στο LMS.

## Σε ποιους απευθύνεται

Σε εκπαιδευτικούς και [[learning-design|σχεδιαστές διδασκαλίας]] στην K-12 και την τριτοβάθμια εκπαίδευση που μπορούν να περιγράψουν το εργαλείο που θέλουν και είναι πρόθυμοι να ελέγξουν τι παρήγαγε ο βοηθός. Ταιριάζει επίσης σε ένα τμήμα που θέλει μία κοινή λίστα ελέγχου πριν δημοσιεύσει οποιοσδήποτε ένα εργαλείο για μαθητές, και σε διδάσκοντες που διδάσκουν [[ai-literacy|επάρκεια σε ΤΝ]] μέσα από την κατασκευή και όχι μέσα από την κριτική.

## Σημειώσεις και επιφυλάξεις

Το κέντρο είναι καθοδήγηση, όχι προϊόν συμμόρφωσης: ο ιστότοπος δεν κάνει κανέναν ισχυρισμό συμμόρφωσης για τον δικό του στόχο WCAG 2.2 AA, απαντά «όχι» στο «κάνει η χρήση αυτών των αρχείων τον ιστότοπό μου συμβατό;», και λέει ότι μια μηχανική αναθεώρηση δεν αντικαθιστά την έγκριση του σχολείου ή τη νομική αναθεώρηση. Το ράφι ασφάλειας δείχνει τα axe-core, Gitleaks, ZAP και Playwright· αυτά είναι αναφορές και όχι συσκευασμένο λογισμικό, και τα επεμβατικά προορίζονται για έναν αναλώσιμο ή ρητά εξουσιοδοτημένο στόχο. Η ανάγνωση δεν απαιτεί λογαριασμό. Η επανακατασκευή των σελίδων HTML απαιτεί Python και `markdown-it-py`, που είναι εξάρτηση κατασκευής και όχι εξάρτηση επισκέπτη. Το αποθετήριο έχει άδεια MIT, ενώ τα έργα τρίτων και τα συνδεδεμένα έργα κρατούν τους δικούς τους όρους, τεκμηριωμένους στο `CREDITS.md`.
