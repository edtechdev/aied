*Αυτόματη μηχανική μετάφραση αυτής της αγγλικής σελίδας, που δεν έχει ακόμη ελεγχθεί από φυσικό ομιλητή.*

Το **Canvas MCP** είναι ένας διακομιστής Model Context Protocol ανοιχτού κώδικα του Vishal Sachdev που συνδέει έναν πελάτη ΤΝ με ένα στιγμιότυπο Canvas LMS: ο πράκτορας μπορεί να απαριθμήσει τις επερχόμενες εργασίες ενός φοιτητή, να διαβάσει τις εργασίες και τις υποβολές ενός μαθήματος, να στείλει μήνυμα σε μια τάξη ή να ελέγξει ένα μάθημα για προσβασιμότητα, όλα μέσα από εργαλεία που εκθέτει ο διακομιστής και όχι με αυτοσχέδια απόξεση οθόνης.

## Τι μπορείτε να κάνετε με αυτό

Ο διακομιστής παρέχει τρεις οικογένειες εργαλείων. Τα εργαλεία φοιτητή απαντούν σε «τι είναι προθεσμία αυτή την εβδομάδα», «έχω υποβάλει τα πάντα», «πόσες προσπάθειες κουίζ μου μένουν» απέναντι στα ίδια τα τελικά σημεία `self` του Canvas. Τα εργαλεία εκπαιδευτικού απαριθμούν και δημιουργούν εργασίες, διαβάζουν υποβολές, βαθμολογούν μαζικά, στέλνουν συνομιλίες και αντλούν αναλυτικά εργασιών. Τα εργαλεία σχεδιαστή μάθησης καλύπτουν ελέγχους ποιότητας μαθήματος και σαρώσεις προσβασιμότητας WCAG. Έως 128 εργαλεία είναι διαθέσιμα συνολικά, αν και το προεπιλεγμένο προφίλ καταχωρεί λιγότερα και τα εργαλεία που ελέγχονται από χαρακτηριστικά ανεβάζουν τον αριθμό. Πάνω από τα εργαλεία, οκτώ δεξιότητες πράκτορα συσκευάζουν συνταγές πολλών βημάτων — ένα εβδομαδιαίο σχέδιο, έναν πρωινό έλεγχο υγείας μαθήματος, ένα δέντρο αποφάσεων μαζικής βαθμολόγησης, έναν αγωγό αξιολόγησης από ομότιμους, έναν έλεγχο μαθήματος πριν από το εξάμηνο — εγκαταστάσιμες σε 40+ πράκτορες μέσω του `skills.sh`.

## Σε ποιους απευθύνεται

Σε διδάσκοντες που θέλουν έναν πράκτορα να χειρίζεται την καθημερινή ανάγνωση και ανταλλαγή μηνυμάτων γύρω από ένα μάθημα, και σε [[institutional-ai-infrastructure|θεσμικές ομάδες]] που αξιολογούν τι μπορεί πραγματικά να φτάσει ένας πράκτορας συνδεδεμένος με το LMS. Οι σχεδιαστές μάθησης παίρνουν εδώ το πιο κοντινό πράγμα σε αυτοματοποιημένη αναθεώρηση μαθήματος. Το έργο είναι ένα δουλεμένο παράδειγμα [[agentic-ai|εργαλείων πρακτόρων]] στο επίπεδο του LMS ενός ιδρύματος και όχι ενός γενικού chatbot.

## Σημειώσεις και επιφυλάξεις

Η εγκατάσταση είναι τοπική: Python 3.11 ή νεότερη, ένα token και URL του API του Canvas, και ένας πελάτης MCP, με επέκταση με διπλό κλικ για το Claude Desktop. Ο δημόσιος φιλοξενούμενος διακομιστής έχει αποσυρθεί, οπότε μια κοινόχρηστη ανάπτυξη σημαίνει αυτοφιλοξενία πίσω από την ταυτοποίηση του ίδιου του ιδρύματος. Τα εργαλεία εγγραφής είναι φραγμένα — οι διακομιστές HTTP είναι μόνο για ανάγνωση εκτός αν τα εργαλεία εγγραφής επιτραπούν ρητά, οι διαγραφές απαιτούν token επιβεβαίωσης και η εκτέλεση κώδικα τρέχει σε sandbox που αποτυγχάνει κλειστό. Οι έλεγχοι απορρήτου είναι προαιρετικοί: η ανωνυμοποίηση απαντήσεων, η απόκρυψη email και το φιλτράρισμα PII πρέπει να ενεργοποιηθούν, και το README προσέχει να πει ότι αυτά μπορούν να υποστηρίξουν υποχρεώσεις FERPA χωρίς να θεμελιώνουν συμμόρφωση, η οποία εξαρτάται από την ανάπτυξη και τον πάροχο ΤΝ. Δεν υπάρχει τηλεμετρία στον διακομιστή, αλλά το Canvas και ο πελάτης που επιλέγεται κρατούν τα δικά τους αρχεία καταγραφής. Το έργο έχει άδεια MIT, αναπτύσσεται ενεργά, και οι δικοί του οδηγοί είναι η αυθεντία για τα τρέχοντα ονόματα εργαλείων και τη διαμόρφωση.
