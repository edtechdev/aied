*Αυτόματη μηχανική μετάφραση αυτής της αγγλικής σελίδας, που δεν έχει ακόμη ελεγχθεί από φυσικό ομιλητή.*

Το Code Viva τρέχει μια γραπτή, χρονικά περιορισμένη εκδοχή μιας [[oral-assessment|προφορικής εξέτασης]] για κάθε φοιτητή σε ένα μάθημα προγραμματισμού, περίπου δεκαπέντε με είκοσι λεπτά το καθένα, χωρίς διδάσκοντα στην αίθουσα. Διαβάζει τον κώδικα και το ιστορικό commits που υπέβαλε ένας φοιτητής, γράφει τέσσερις έως έξι ερωτήσεις για τις δικές του συναρτήσεις, ονόματα και commits, και δίνει σε κάθε φοιτητή έναν προσωπικό σύνδεσμο για να απαντήσει.

## Τι μπορείτε να κάνετε με αυτό

Οι υποβολές έρχονται από εξαγωγή Gradescope, λήψη zip από το Canvas, zip με φάκελο ανά φοιτητή ή το GitHub Classroom με token ανάγνωσης. Ο διδάσκων ορίζει τη διάρκεια της συνεδρίας, τον αριθμό ερωτήσεων και την προθεσμία, σημειώνει παράταση χρόνου στο 1,25x έως 3x, και διαβάζει, επεξεργάζεται ή αντικαθιστά τις παραγόμενες ερωτήσεις πριν στείλει τους συνδέσμους. Οι ερωτήσεις καλύπτουν βασικές περιπτώσεις αναδρομής, φρουρούς ορίων, επιλογές δομών δεδομένων, αδιαφανή ονόματα μεταβλητών, κλίμακα και ιχνηλάτηση, προτάσεις από την προδιαγραφή της εργασίας, και μοτίβα commits όπως ένα μαζικό commit ή ένα commit αργά τη νύχτα. Οι απαντήσεις επιστρέφουν ως κωδικός απόκρισης, και η οθόνη ανασκόπησης δείχνει κάθε απομαγνητοφώνηση δίπλα σε μια προτεινόμενη βαθμολογία 0 έως 3 με τις προτάσεις στις οποίες στηρίζεται, μαζί με μια ουρά σημαιοδότησης ταξινομημένη κατά το πόσο δικαιολογείται μια συζήτηση. Τα αποτελέσματα εξάγονται σε CSV, και έντεκα μαθήματα επίδειξης αφήνουν τον αναγνώστη να δοκιμάσει όλο τον κύκλο σε επινοημένα δεδομένα.

## Σε ποιους απευθύνεται

Σε διδάσκοντες μαθημάτων προγραμματισμού που θέλουν απόδειξη ότι ένας φοιτητής μπορεί να εξηγήσει τον δικό του κώδικα, και που θα προτιμούσαν να μιλήσουν σε έναν σύντομο κατάλογο φοιτητών παρά σε όλους· οι ερωτήσεις για τα commits το καθιστούν μορφή [[process-oriented-assessment|αξιολόγησης προσανατολισμένης στη διαδικασία]].

## Σημειώσεις και επιφυλάξεις

Όλα τρέχουν στον περιηγητή: το μάθημα βρίσκεται στην τοπική αποθήκευση με εξαγωγή JSON, οι ερωτήσεις ταξιδεύουν στο τμήμα του συνδέσμου που οι περιηγητές δεν στέλνουν σε διακομιστές, και οι απαντήσεις επιστρέφουν μόνο ως κωδικοί που επιλέγουν να στείλουν οι φοιτητές, ώστε κανένα δεδομένο φοιτητή να μη φτάνει σε τρίτο. Η γεννήτρια ερωτήσεων είναι βασισμένη σε κανόνες και όχι σε μοντέλο. Κατά δική του δήλωση, ο αναγνώστης κώδικα είναι ευρετικός, οπότε ασυνήθιστη μορφοποίηση ή macros μπορούν να κρύψουν μια συνάρτηση, και μια βαθμολογία μπορεί να επιβραβεύει το να ξέρει κανείς το λεξιλόγιο αντί να καταλαβαίνει τον κώδικα, γι' αυτό οι βαθμολογίες είναι προτάσεις που εγκρίνει ο διδάσκων και γι' αυτό συμβουλεύει να κρατούνται χαμηλά τα διακυβεύματα. Δεν δημοσιεύεται άδεια ούτε αποθετήριο πηγαίου κώδικα, και επειδή οι σύνδεσμοι μεταφέρουν τις ερωτήσεις φτάνουν σε λίγα kilobyte, αρκετά μακριά ώστε να σπάσουν σε ένα πλαίσιο μηνύματος συστήματος διαχείρισης μάθησης.
