**Education Agent Skills** je knihovna 165 agentních dovedností pro učitele, vedení škol a lidi, kteří stavějí vzdělávací nástroje. Dovednosti jsou rozděleny do dvaceti domén pokrývajících pedagogiku, vědu o učení, [[curriculum-design|kurikulum]], hodnocení a regeneraci a každá z nich je napsána tak, aby ji načítal [[agentic-ai|agent]], nikoli aby se četla jako dokument.

## Co s ní můžete dělat

Dovednosti se instalují do Claude Code, Codex a Hermes, buď jako plugin, nebo zkopírováním složek, takže stejná knihovna funguje na několika agentních površích. Hostovaný server MCP zpřístupňuje sbírku jako nástroje pro agenty, kteří nemohou instalovat dovednosti lokálně, a repozitář obsahuje registr i předpřipravený balík, takže server může sbírku obsloužit, aniž by při nasazení četl jednotlivé soubory.

Odlišujícím tvrzením projektu je jeho zakotvení v důkazech: dovednosti citují důkazy, o něž se opírají, a historie repozitáře ukazuje, že se tato disciplína vymáhá, nikoli jen prohlašuje, včetně sloučené opravy, která odstranila nepodložené připsání a opravila popis testovaného ochranného opatření v citované studii.
