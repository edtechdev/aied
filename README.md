# AI in Education Wiki

A structured, interlinked knowledge base tracking research at the intersection of artificial intelligence and education.

**Live site:** [edtechdev.github.io/aied](https://edtechdev.github.io/aied)

## About

Curated through daily scans of arXiv, Semantic Scholar, and OpenAlex for the latest evidence on:
- AI tutoring and intelligent tutoring systems
- Automated assessment and feedback
- AI literacy and scaffolding
- Learning analytics and student modeling
- Critical thinking and metacognition
- Equity, policy, and institutional change

**540 concept pages** · **163 tags** · **363 journal entries**

## Structure

- `index.html` — Home page with recent journal entries and searchable page list
- `journal.html` — Full chronological journal
- `pages/` — Individual concept pages
- `search.html` — Full-text search powered by FlexSearch
- `wiki-source/` — Source markdown files (concepts, raw papers, journal, index)

## Hosting

This site is hosted on **GitHub Pages** from the root of the `main` branch. The static HTML is regenerated after each daily scan.
