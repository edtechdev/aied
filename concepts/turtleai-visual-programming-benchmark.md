# TurtleAI: Benchmarking Multimodal Models for Visual Programming in Turtle Graphics
**Wen et al. (2026)** — ArXiv.
📄 [Full text (arXiv)](https://arxiv.org/abs/2606.03626)

Introduces TurtleAI benchmark (823 tasks). Finds that current VLMs (GPT-5, o3) struggle with spatial reasoning in educational graphics. Fine-tuning improves visual-code alignment. [[benchmark]], [[cs-education]], [[k-12]], [[generative-ai]], [[spatial-reasoning]].
